## ?? Quick Start

### 1. **Install Dependencies**
```bash
cd DoctorAppointmentSystem.client
npm install
```

### 2. **Run Both Projects**
In Visual Studio:
- Set **Multiple Startup Projects**
- Start both `DoctorAppointmentSystem.API` and `DoctorAppointmentSystem.client`
- Or press F5 to run

### 3. **Login**
- Email: `admin@dentalclinic.com`

## ?? Configuration

The frontend automatically proxies API requests to your backend:
- Frontend: `https://localhost:64293`
- Backend API: `https://localhost:7230` (or your configured port)
- All `/api/*` requests are forwarded to the backend
